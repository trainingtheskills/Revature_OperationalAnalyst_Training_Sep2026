# Week1 - Day1 - Excel Foundation
#==================================



Open Microsoft 365
Go to: https://m365.cloud.microsoft
We recommend using a private/incognito browser window if you are already signed in to another Microsoft account.
Enter your Revature email address
Your username will normally be in this format:
firstname.lastname@revature.net
Please use the exact email address provided to you.
Important: The domain is @revature.net, not @revature.com.
Enter your temporary password
Use the temporary password provided to you.
You will be asked to change this password during your first sign-in.
Create your new password
Your new password must:
Be between 8 and 256 characters
Include at least 3 of the following 4:
Uppercase letter
Lowercase letter
Number
Symbol
Be different from your temporary password
Not be a commonly used or easily guessed password
Complete the sign-in
After changing your password, follow the on-screen instructions to complete the Microsoft 365 sign-in process.
